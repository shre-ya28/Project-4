# 🎯 Predictive Modeling and Risk Scoring for Bank Customer Churn

A predictive churn intelligence system for a European retail bank (France, Spain,
Germany) — built for **Unified Mentor / The European Central Bank** project brief.

Traditional churn analysis explains *why* churn happened. This project goes further:
it assigns every customer a live **churn probability score** so retention teams can
act **before** a customer leaves — enabling proactive campaigns, personalized offers,
and targeted engagement instead of broad, reactive ones.

## 📊 Key Results

| Metric | Value |
|---|---|
| Best Model | **Gradient Boosting** |
| ROC-AUC | **0.870** |
| Accuracy | **87.2%** |
| Precision / Recall | 79.4% / 50.1% *(adjustable via threshold)* |
| Top Churn Driver | Number of Products × Engagement interaction |

Full methodology, model comparison, and explainability analysis are in
[`reports/research_paper.md`](reports/research_paper.md) /
[`reports/Research_Paper.pdf`](reports/Research_Paper.pdf), with a stakeholder-facing
version in [`reports/Executive_Summary.docx`](reports/Executive_Summary.docx).

> This project is the predictive companion to the earlier **Customer Segmentation &
> Churn Pattern Analytics** project — that project explains *where* churn concentrates;
> this one predicts *which individual customers* are at risk and *why*.

## 🧠 Methodology

### 1. Data Preprocessing
- Missing-value handling (median/mode imputation — defensive, none present in the source data)
- Drop non-informative identifiers (`CustomerId`, `Surname`)
- One-hot encode `Geography` and `Gender`
- Standard-scale numerical features for the Logistic Regression baseline

### 2. Feature Engineering
| Feature | Formula |
|---|---|
| BalanceToSalaryRatio | `Balance / (EstimatedSalary + 1)` |
| ProductDensity | `NumOfProducts / (Tenure + 1)` |
| EngagementProductInteraction | `IsActiveMember × NumOfProducts` |
| AgeTenureInteraction | `Age × Tenure` |

### 3. Train–Test Strategy
Stratified 80/20 split preserving the churn class ratio, with 5-fold stratified
cross-validation used to confirm each model's ROC-AUC is stable.

### 4. Models Trained
Logistic Regression (baseline) · Decision Tree · Random Forest · Gradient Boosting ·
**XGBoost (optional — used automatically if installed; the pipeline degrades
gracefully if not)**

### 5. Evaluation
Accuracy, Precision, Recall, F1-score, and ROC-AUC for every model, plus confusion
matrices and ROC curves. The best model is selected by ROC-AUC and saved for
deployment; all trained models are retained for comparison.

### 6. Explainability
- Global feature importance (native for tree models, |coefficient| for Logistic Regression)
- Partial dependence plots for the top churn drivers
- A model-agnostic **local feature contribution** method (per-customer, SHAP-free) that
  powers the app's "why this score" explanations
- Optional true **SHAP value analysis** in the notebook if `pip install shap` is available

## 🚀 Getting Started

### 1. Clone and set up the environment

```bash
git clone https://github.com/<your-username>/bank-churn-risk-scoring.git
cd bank-churn-risk-scoring
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. (Optional) Retrain the models

Trained model artifacts are already included under `models/`, so you can skip this
step and go straight to the notebook or the app. To regenerate them from scratch:

```bash
python src/train_models.py
```

This retrains all five (or four, without XGBoost) models, re-evaluates them, and
overwrites everything in `models/`.

### 3. Explore the analysis

```bash
jupyter notebook notebooks/Model_Development_and_Evaluation.ipynb
```

### 4. Run the Streamlit dashboard

```bash
streamlit run app/streamlit_app.py
```

The dashboard opens at `http://localhost:8501` with four modules:

- **🧮 Risk Calculator** — enter any customer profile, get a live churn probability,
  a risk band (Low / Medium / High), a gauge visualization, and a chart explaining
  what pushed the score up or down.
- **📈 Probability Distribution** — histogram of the model's churn probabilities on
  the test set, an adjustable classification threshold with live precision/recall/F1,
  and ROC curves + a full metric comparison across every trained model.
- **🔍 Feature Importance Dashboard** — global feature importance plus an interactive
  partial-dependence sweep for any feature.
- **🧪 What-If Scenario Simulator** — start from a preset or custom customer profile,
  adjust engagement and product values, and watch the churn probability respond live,
  including a product-count sensitivity chart.

## 🔑 Predictive Target

- **Target variable:** `Exited` (1 = churned, 0 = retained)
- **Prediction output:** a continuous churn probability (0–1) **and** a binary risk
  flag derived from an adjustable threshold (default 0.5, tunable per retention
  channel in the app)
